# Data Analyst Portfolio

Eight portfolio-ready analytics projects spanning entertainment, energy, healthcare, commercial analytics, aviation, master data management and temporal clustering.

## Projects
1. TMDB 2026 Movie Analysis
3. Electricity Demand & Grid Stress
7. Streaming Content Portfolio / Renewal Decisions
9. Pharmaceutical Sales-Force Effectiveness
11. Healthcare Market Expansion / Site Selection
16. Airline Delay Propagation Network
19. Customer 360 Master Data Management
23. Music Chart Momentum & Breakout Detection

Every project contains `analysis_notes.txt`, a plain-text Notepad-friendly guide explaining the program, execution logic, important variables, formulas/algorithms, methods used, assumptions and limitations.

Each project also contains a Python entry point, SQL example and requirements file. Raw datasets are intentionally not committed; follow each project README to supply public or synthetic inputs.
