# Data Analyst Portfolio

Portfolio-ready analytics projects spanning entertainment, energy, healthcare, commercial analytics, aviation, master data management and temporal clustering.

Every project contains `analysis_notes.txt`, a plain-text Notepad-friendly guide explaining the program, execution logic, important variables, formulas/algorithms, methods used, assumptions and limitations.

Each project also contains a Python entry point, SQL example and requirements file. Raw datasets are intentionally not committed.
