PROGRAM: Music Chart Momentum & Breakout Detection
LOGIC: create song ID -> order each song by chart week -> lag rank -> momentum=previous rank-current rank (positive means improvement) -> acceleration=change in momentum -> reshape first 8 weeks into trajectories -> KMeans exploratory clustering.
VARIABLES: song_id=artist+song identity; previous_rank=prior week's rank; momentum=weekly rank improvement; acceleration=change in momentum; week_number=weeks since observed entry; first8=wide trajectory matrix; trajectory_cluster=exploratory KMeans group.
METHODS: temporal lag features; first derivative (momentum); second-order change (acceleration); pivot/trajectory representation; KMeans clustering with random_state for reproducibility. A future-window breakout label can define breakout as rank >40 followed by a best rank <=20 within four weeks; this is a project definition. Mann-Whitney U can compare breakout/non-breakout features. No bubble sort is used; ranking/order uses pandas optimized sorting.
LIMITATIONS: Chart rank is ordinal; clustering Euclidean rank trajectories is exploratory. Songs missing eight complete weeks are excluded from clustering, creating survivorship bias.
