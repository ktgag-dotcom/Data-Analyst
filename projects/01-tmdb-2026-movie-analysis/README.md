# 2026 Movie Analysis

Portfolio analysis of 2026 films using TMDB data. The project cleans movie metadata, derives ROI and popularity metrics, compares genres, and produces decision-oriented summaries.

## Run
1. Download/export TMDB movie data to `data/movies.csv`.
2. `pip install -r requirements.txt`
3. `python main.py`

## Questions
- Which genres have the strongest median revenue and ROI?
- Does budget correlate with revenue?
- Which films over/under-perform their budget?

See `analysis_notes.txt` for program logic, variables, formulas, and methods.
